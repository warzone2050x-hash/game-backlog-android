# GAME BACKLOG Android

Native Android prototype for GAME BACKLOG.

## Current features
- Local game library
- Playing Now / Completed / Dropped / Wishlist
- Search and filters
- Add, edit and delete games
- Random game picker
- Offline local persistence
- Android 8+ (minSdk 26)
- Targets Android 16 / API 36

GitHub Actions builds a debug APK automatically.
